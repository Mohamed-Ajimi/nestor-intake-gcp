## What Was Done

**Defect 2 (nav labels hardcoded Dutch):** `AdminNavItem` now carries `labelKey` instead of
`label`. ProductShell renders `t(item.labelKey)` at both nav render sites (primary items map
and the superadmin Beheer manage section). `admin.pulse.tsx` passes `nav.pulseNewIntake` /
`nav.pulseIntakes` / `nav.pulseClients` / `nav.pulseSearch`; `admin.sales.tsx` passes
`nav.salesNewProject` / `nav.salesProjects`. All three catalogs (nl/fr/en) gained an identical
9-key top-level `nav` block. The `items !== ADMIN_NAV` reference-equality guard is preserved —
ADMIN_NAV remains one exported const and the three Beheer routes were not touched.

**Defect 1 (no language switcher for user role):** `/intake` (intake.index.tsx) mounts
`<LanguageSwitcher persist />` in the header chrome row, grouped with the email/logout cluster,
constrained in a `w-28` box (the switcher trigger is `w-full`). File header comment updated to
note the page now hosts the switcher while still not mounting ProductShell/space switcher.

**Defect 3 (decomposed missing from filter):** `STATUS_FILTER_VALUES` gained `"decomposed"`
between `validated_by_client` and `in_research` (machine order). `intakesList.filter.decomposed`
added to all three catalogs reusing the existing status labels verbatim: nl "Gedecomposeerd",
fr "Décomposé", en "Decomposed". Each catalog now has 3 occurrences of `"decomposed"`
(status + statusBanner + filter).

**Defect 4 (lists don't refetch on space switch):** Both load effects now depend on
`[activeSpaceId]`. `admin.pulse.clients.tsx` newly imports and reads `useActiveSpace()`.
No API call signatures changed — the space is threaded internally via `withActiveSpace`,
and the existing `cancelled` flags handle stale responses.
