## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| provider fact lists → feed row | `record.provider`, `record.reason` and claim text are model- or provider-influenced strings reaching a persisted, operator-visible row. |
| gate model output → feed row | `claim["gate"]["reason"]` is written by `apply_gates` from a model response and is rendered in a `plan` row. |

|-----------|----------|-----------|-------------|-----------------|
| T-21-05-01 | Denial of service | one `plan` row per dropped claim in the gate stage | mitigate | Bounded by `_gate_budget` at `MAX_ROWS_PER_STAGE` (25 by default), with the elision stated as a visible row and asserted by Task 3 test (e).
