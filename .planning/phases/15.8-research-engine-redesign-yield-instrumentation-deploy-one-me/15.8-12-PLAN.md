## The cost trap the table must defeat

15.8-08 established that `run.cost_pending` is set only via `dr_cost_pending`, which the openai
branch never sets, and that the run total is
`COALESCE((SELECT SUM(cost_usd) FROM audit_log WHERE run_id = :id), 0)` — and `SUM` skips NULL rows.
So the NEXT run's total is a floor too, by the same mechanism. Comparing $53.48 to a new total
without counting NULL-cost rows on both sides is comparing a floor to a floor and calling it
agreement. 15.8-08 records the count query in `15.8-PRECONDITIONS.md`; the shape is
`SELECT count(*) FROM audit_log WHERE run_id = :id AND cost_usd IS NULL`.
