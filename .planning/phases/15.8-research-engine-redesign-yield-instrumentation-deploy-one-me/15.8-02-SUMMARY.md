## 2. What was built

### Task 1 — WR-04 (`research_division.py`), commit `63e1d39`

`_bound_groups_to_winners` was documented "PURE, never raises" with a body containing no `try`.
`list(groups or [])` raised `TypeError` on any non-iterable, **between the paid workshop and the
paid angles**. Fixed in three layers, rejecting both of 15.6's offered options (returning `[]` for one
hostile group would discard every healthy group with it; downgrading the docstring leaves the raise in
production):

1. **`_as_list`** — one new module-level PURE helper. Attempts `list(value or [])`, returns `[]` on
   failure. Attempting first and only catching the failure is deliberate: it preserves **exactly**
   today's behaviour for every input that already works, including the two shapes the callers lean on
   (a dict iterates keys then fails `isinstance`; a str iterates chars, same).
2. **Fail CLOSED** — `allowed_texts` is read once into a local set through the same tolerance. An
   unreadable bound becomes an EMPTY bound: members dropped, group dropped whole, `_divide_from_winners`
   falls back. Chosen direction, because this bound is the only real spend control left (T-15.2-61).
3. **Outer per-group backstop** — `try/except` + `continue`, counting `dropped_malformed` **apart** from
   the two existing causes, with its own warning naming it a malformed record and **not** the bound.

**Reachability:** `_divide_from_winners`' step 2 ran the identical expression *before* the helper, so a
helper-only fix would have been green in a unit test and still fatal live. Fixed in the same commit.

### Task 2 — WR-06 (`pipeline.py`), commit `4ee8e48`

`_dispatch_was_uniform(angles, groups, streams=None)` added immediately before `_angle_copies`.
Counts copies per corroboration key; True only when groups is non-empty **and** keys == groups **and**
every key carries the expected stream count. `streams` defaults to `len(_D6_STREAMS)` (asserted as a
PROPERTY, never as an exact provider set). Tolerant iteration written **locally**, not imported across
the `research_division` seam a sibling plan edits this wave.

The contradicting comment is rewritten. `_corroborated`, the weaker fallback wording, and
`_stage_log_counts(..., corroborated=…)` are all unchanged.

## 4. Deviations from Plan

### **[Rule 1 — Defect in the plan's own acceptance criteria] The layer-3 backstop MASKS the WR-04 mutants at the return-value level**

- **Found during:** Task 1, building the mutation table.
- **Issue:** the plan's acceptance criterion says *"restore the raw `key in allowed_texts` and confirm
  the `None` bound **RAISES**"*. It does not raise. Layer 3 (the outer per-group backstop, which the same
  plan mandates) **catches** that raise, counts it as a malformed record, and returns `[]` — the *identical*
  return value the fail-closed path produces. **M2 and M3 are invisible to any `== []` assertion.**
- **Consequence if unaddressed:** the two tests would have been GREEN ON UNFIXED SOURCE. This is the
  same class as D-W5-7's "test the test" row, reached from a different direction: the fix's own third
  layer makes the first two unprovable through the return value.
- **Fix:** every WR-04 test asserts the **cause channel** — *which* warning fired — and explicitly
  asserts `"MALFORMED" not in messages` for the broken-bound case. That is what makes the mutants red.
  The three drop counters are now load-bearing rather than decorative.
- **Files:** `tests/test_research_division_assignment.py`. **Commit:** `63e1d39`.

### **[Rule 1 — Bug] Both `grep -v '^ *#'` gates are self-invalidated by DOCSTRING prose**

- **Found during:** Tasks 1 and 2, running the plan's own gates.
- **Issue:** both acceptance gates filter with `grep -v '^ *#'` and state the intent *"comments excluded,
  so the historical prose in the docstrings cannot self-invalidate the gate."* **`grep -v '^ *#'` excludes
  `#` comments only — a docstring is not a `#` comment.** Writing the historical defect verbatim into a
  docstring (the natural way to record it) made both gates **RED on the FIXED source**.
- **Fix:** both docstrings describe the old expression in prose instead of reproducing it, each with an
  inline note saying **why** it is not quoted verbatim, so a future editor does not helpfully "restore"
  it and turn the gate red. Both gates now return 0.
- **For 15.8-13 and any future gate author:** to filter *all* prose, the exclusion must cover docstrings
  too, not just `#` lines. This is the "guard the invariant, not a proxy" trap in a new place.

### **[Rule 2 — Missing critical coverage] Two Task-2 mutants were initially non-discriminating**

- **Found during:** Task 2, first mutation run. M2 (drop the emptiness guard) and M3 (ignore
  `corroboration`) both showed **no red** against the four probes the plan's `<behavior>` rows suggested.
- **Why:** for M2, `groups=[]` with *keyed* angles is already rejected by the key-count equality
  (1 key ≠ 0 groups). Only the **0-keys-and-0-groups** shape reaches the vacuous `0 == 0`, where
  `all()` over an empty mapping is True.
- **Fix:** added the vacuous probe and the stray-non-corroborated-angle probe; both mutants now go red.
  `test_empty_groups_is_never_uniform` gained a third assertion (the keyless case) and its docstring
  states that the first two assertions do **not** pin the guard.
