<objective>
Drop `nestor.skill_runs.started_at`. `23.1-CONTEXT.md` § 5 lists it as dead, and the codebase
already documents it as such: `intake_routes.py:177` states "``skill_runs.started_at`` is a

Purpose: a nullable column that nothing writes is a permanent invitation to write it — and the
next reader who reaches for "when did this run start?" will find two candidates, pick the
always-NULL one, and ship a clock that reads 00:00. The comment at `:177` exists because that
already nearly happened once.

that it describes a column that no longer exists.

  run's real start timestamp, stamped by Postgres at INSERT, and that the frontend previously

  reason the projection looks the way it does.
