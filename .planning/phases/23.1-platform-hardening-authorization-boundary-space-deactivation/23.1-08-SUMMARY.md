## Deviations from Plan

### [Rule 1 — false plan claim] "the sole caller is admin.sales.projects.$id.tsx:1081"

`:1073` reads `battlecard.blocks && Object.keys(battlecard.blocks).length > 0`, so the **blocks

exports `null` without `VITE_SUPABASE_*`, and every data path there is `if (!supabase)`-guarded.
But the badge loss is twice the blast radius stated. Recorded in DEF-23.1-01.

analog". Measured: `asString` exists **only** in `NestorBriefingPDF.tsx`, the file being deleted.
`ContextPackPDF.tsx` has no `asString` and does not import `pick` at all. Following the

argument is preserved verbatim; only the example changed.

The plan grants this explicitly ("or a new `.test.ts` beside it if that file's scope does not
fit — your call"). `localizeSchema.test.ts` is scoped to the `localizeSchema`/`pick` resolver;
importing six locale catalogues there would muddy it. `statusCatalog.test.ts` is a `.ts` file
in `src/lib/i18n/`, so `vitest.config.ts`'s `src/**/*.test.ts` collects it — confirmed by the
run showing 10 files.

The comment said labels are looked up in the **admin** catalog. After the dedupe the pill reads

been a half-true comment pointing a future reader at the wrong catalogue. Rewritten to state
