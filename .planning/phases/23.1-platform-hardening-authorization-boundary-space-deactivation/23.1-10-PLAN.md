## THE ORDERING RULE IS LOAD-BEARING, NOT COSMETIC

Six of the eight also take `repo: IntakeRepository = Depends(get_tenant_repo)`. FastAPI
resolves dependencies in SIGNATURE ORDER, and `get_tenant_repo` raises a **403** for a
null-space user (the D-04 default-deny). If the repo resolves first, a null-space user learns
the endpoint exists. **Declare `identity: Identity = Depends(superadmin_gate)` BEFORE the
`repo` parameter** — this is the contract `gates.py`'s docstring states and the existing
research denial suite pins. For the two verbs with no `repo` parameter (`deliver_report`,
`replace_report`), order is moot; make the change anyway so all eight read the same.
