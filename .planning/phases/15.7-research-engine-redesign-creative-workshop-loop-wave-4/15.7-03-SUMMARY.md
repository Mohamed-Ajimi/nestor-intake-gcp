### Design choices made within Claude's Discretion

- **The round-count formula** (explicitly delegated by CONTEXT `<decisions>` / Claude's Discretion):
  `min(MAX, max(MIN, ceil_log2(n)), n - 1)`, with `ceil_log2` implemented as `(n - 1).bit_length()`
  rather than `math.log2`. **No float is involved anywhere.** A round count derived through a float
  is a round count that can differ by one on another machine, and determinism is the reason the
  pairing and standing code is written the way it is. This yields exactly the required 17 -> 6 and
  3 -> 2.
- **`_as_entries` keeps non-dict elements as `{}` rather than dropping them.** The never-drop rule
  is an invariant of this module and an unexpected input shape is not a licence to start deleting
  positions from a pool another stage reconciles against.
- **`_count_of` accepts a collection and takes its length.** A caller that passes the winner *list*
  to `round_metrics` gets 3, not a silent 0. Instrumentation that quietly reports zero is worse than
  absent instrumentation, because a zero looks like a measurement.
- **`degradation_reason` composes up to two sentences** (WEAK and resurrected), joined with a space.
  The plan named only the WEAK case; quality can fail either way, so both are covered.
