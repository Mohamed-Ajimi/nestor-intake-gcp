## THE `groundingChunks` SUBSTITUTION — read this before reviewing

D-R10's CRITICAL implementation note says the admission evidence "must come from
`groundingChunks`". **THIS ENGINE HAS NO `groundingChunks`.** It is a Gemini
grounded-search concept, and it is what the measurement harness happened to run on; the
deployed workshop orients through **Anthropic server-side tools**.

The equivalent real-search-result channel here is **`skeptic._collect_citation_urls`**
(`skeptic.py:177`) — the same function `workshop._one_orientation` already uses at
`workshop.py:855`. It reads three block types and nothing else:

- `web_search_tool_result` → `.content` is a list of `web_search_result` carrying `url`
- `web_fetch_tool_result` → `.content` is a `web_fetch_result` carrying `url`
- `text` → `.citations` may carry `url`

A `tool_use` block is **not** one of them, which is exactly the property D-R10 wants. The
decision's INTENT — the evidence comes from a real search result and never from the
model's own output line — is honoured exactly; only the vendor noun changes. This is
recorded in the module docstring (point 2) and in the `EMIT_ADMISSION_TOOL` comment so a
later reader does not go hunting for a `groundingChunks` reader that was never going to
exist here.

## The corrected admission test

Read the original way — *"is there a published answer to this?"* — the rule rejected
**all four** invented angles in the harness run, zero survivors, including the
network-density question D-R10 exists to admit. It admits already-documented angles and
rejects novel ones: a novelty filter pointed backwards. `_ADMISSION_SYSTEM` therefore asks
whether the **entities, markets, mechanisms and metrics EXIST** and whether desk research
could plausibly settle the question, and says explicitly that an already-published answer
is **not** the test and must not count against the angle.

`"no source, no slot"` is not weakened — it moved from *"only orientation may originate an
angle"* to *"only evidence may admit one"*.

### 1. [Rule 3 — blocking] The plan's `<worktree_preflight>` fired: the worktree was STALE

`git merge-base HEAD 3d6f3fb…` returned `a3a0c96` — the exact stale ref the memory note
records as 7/7 in phase 15.6. Corrected with `git reset --hard 3d6f3fbeeb8c3c6b5b12cda4afb3ea1823b86fd3`
before any file was read or written. All three positive sentinels (`_norm_url`,
`resolve_redirects`, `_collect_citation_urls`) were then confirmed present. **This is now
8/8.**

### 2. [Rule 3] `resolve_redirects` is `async`; the plan's phrasing implied a sync helper

`redirect_resolver.resolve_redirects` is `async def` (`redirect_resolver.py:245`), so the
batch resolution is awaited inside `admit_invented_angles` rather than called from the
pure `admission_evidence`. This is why the function splits into three phases (sessions →
one batch resolution → decisions) and why `admission_evidence` takes an already-resolved
map as a keyword. The plan's requirement — pure evidence rule, impure thin shell, one
resolution per batch — is met exactly; only the sequencing is explicit.

### 3. [Rule 2 — correctness] The `model` and retry-feed authorities are reached FUNCTION-LOCALLY

`_WORKSHOP_MODEL`, `_feed_mark_retry` (both `workshop.py`), `_RANK_MODEL`
(`workshop_rank.py`) and `gates._make_config` are imported **inside the functions that use
them**, not at module level. Module-level imports would work today and become an **import
cycle** the moment plan 15.7-06/09 wires this module into `workshop.py` or
`workshop_rank.py`. This keeps one authority per value (no CR-01-class duplicate constant)
while removing the cycle risk — the same pattern `redirect_resolver.is_redirect_url` uses
for `VERTEX_REDIRECT_HOST`. Each has a `try/except` fallback so a missing constant is
never a crash.

### 4. [Rule 2 — correctness] `_IGNORE_INSTRUCTIONS` is DUPLICATED, not imported

The plan says to carry the sentence "verbatim from `workshop_rank._IGNORE_INSTRUCTIONS`'s
register". It is duplicated as a literal rather than imported, on the same reasoning
`discovery_bracket._DISCOVERY_TEXT_CHARS` is duplicated: **a sibling plan is editing
`workshop_rank.py` in this same phase**, and an import would couple two parallel
worktrees for the sake of one sentence. (`workshop_rank` itself carries it verbatim from
`grouping.py:162`, so this is the third copy by design, not by accident.) Recorded in a
comment at the definition.

### 5. [Rule 1 — corrected during the task] The `required` comment named `source_url` inside the schema block

The first draft put the "why there is no URL field" comment **inside** the
`EMIT_ADMISSION_TOOL` dict literal, which made `grep -icE "url"` over the schema block
return 1 and failed the plan's own acceptance criterion. The `repr()`-based test passed
because comments are not in a repr — **the greppable criterion was the stricter of the
two, and it was right**. The reasoning moved up into the `#:` comment above the literal;
the dict literal is now free of the substring, and a comment there says so on purpose.
