## 2. What was changed

### One rule, spelled once — `_compose_parent_assignment()` (new, `research_division.py`)

Full untruncated question, blank line, then the brief. **No character cap.**
Called from all three sites that compose a mandate assignment, so they cannot

file ("one rule, spelled once, is the whole point").

**all three of its consumers already document it as the provider-facing text**:

- `intake.py:25` — *"self-contained, multi-line assignment"*
- `divide():1561` — *"the real text divide() sends to the researcher; the label above is only the display key"*
- `_divide_from_winners:1215` — uses it verbatim as the parent assignment

So fixing it here also fixes `divide()` and the operator display (`pipeline.py:4117`),
with no second code path.

### `pipeline.py` — the dead `parent_prompts=` revived (as instructed, preferred route)

Maps each label → its full text, sourced from `parsed.questions` ∪
`detect_explicit_questions(brief)` (the same detector the workshop falls back to,
reused not re-written). **A label is a PREFIX of its text by construction**, which
is the entire matching rule — so **no copy of the `120` lives in `pipeline.py`** and
`_LABEL_MAX_CHARS` can move without this drifting.
