## What plan 09 decided — these are now facts about the code

- **Evolve division of labour:** `evolve_generative` runs per-round inside the loop and does
  GENERATION; `evolve_winners` runs once after the loop and does SHARPENING. **`langs` is why
  the second survives** — the D7 acceptance criterion is what made leaving this open safe.
- **`born_round` = the round a candidate FIRST COMPETES IN (N+1)**, not the round it was
  written in. Selection precedes evolve within a round, so stamping the writing round would
  have made exit criterion 3 permanently true — a criterion that always passes.
- **KILL split:** a killed candidate is a RESTATEMENT (never barred) when it is part of a
  near-duplicate family (`merged_from`, or a live candidate sharing its `cluster_key`);
  otherwise a DEFECT, and it bars. **Fails safe towards NOT barring.** Deliberately not matched
  on flaw text — that is model prose in the run's own language and would silently never fire on
  a Dutch or French run.
- **Observed exit-round range:** `[3,3,3,3,3,4]` (Tasks 1+2) and `[4,4,3,3,4,3]` (Task 3),
  asserted as `2 <= round < cap`. **Never assert a constant** — evolve runs at temperature 1.0.
- **Test counts:** `test_workshop_loop.py` 42 → **67**; `test_workshop_languages.py` **50**;
  `test_engine_e2e_stubbed.py` 12 → **13**.

## Process lessons that keep paying

- **The stale-worktree trap is now 15 of 15.** Both plan-09 worktrees were cut from `a3a0c96`
  (595 and 601 commits behind) and `git rev-list --count BASE..HEAD` returned **`0` — green —
  both times**. Only `git merge-base HEAD <BASE>` catches it. A variant also fired: a
  `cd <worktree> || cd <main-repo>` fallback silently succeeded on the **main repo** path, so
  the command stopped measuring what it claimed. **Pin paths with no fallback.**
- **A stale scope guard must be NARROWED, never retired.**
  `test_workshop_rank_is_not_edited_by_this_plan` went red on sanctioned code; it was rewritten
  to assert the two things it was really protecting (the scope lock still exists in scoped form;
  `workshop_evolve` is still imported function-locally) rather than deleted.
- **Tests that pass for the wrong reason are the recurring failure mode this phase.** Plan 08's
  Guard 2 test exercised Guard 1; plan 09's D7 `langs` test was vacuous twice (deleting the
  sweep and bypassing `evolve_winners` each left the other writing `langs` — the case that
  bites is a client question with **no** candidates, where `_verbatim_winner` sets `langs: []`
  and skips evolve); Task 3's late-newcomer test passed until it was rewritten to one entrant.
  **The semantic drop had never fired in any test** before Task 3 caught it.
- **Tell executors to report contradictions rather than silently choosing.** Every real defect
  found this phase came from checking an instruction instead of following it — including both
  corrections at the top of this file.
- `.planning/` is **gitignored** — every planning file needs `git add -f`.
- **Write SUMMARYs incrementally.** Two agent runs in this phase were lost to dropped
  connections during a single large SUMMARY write.
