## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23.5-01-E | Elevation of privilege | `override_status` | mitigate | `Depends(superadmin_gate)` declared BEFORE `Depends(get_tenant_repo)`; pinned by `_GATED_VERBS` membership in `test_operator_verb_gate.py` (both the shared-gate audit and the ordering audit) |

| T-23.5-01-T | Tampering | status value from the request body | mitigate | allow-list `_OVERRIDE_STATUSES` (422 on anything else) + explicit `_OVERRIDE_FORBIDDEN` 409 for `in_research`; no free-text status ever reaches `repo.patch` |

| T-23.5-01-R | Repudiation | an operator silently re-writing an intake's history | mitigate | one `audit_log` row per accepted call, `metadata={"from","to","override":true}`, written on `repo.session` so it commits or rolls back with the status change |
