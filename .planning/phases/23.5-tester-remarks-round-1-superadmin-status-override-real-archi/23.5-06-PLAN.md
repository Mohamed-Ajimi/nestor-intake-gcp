## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored `source.resolved_url` -> a clickable link in a delivered report | a value originally taken from a remote host's `Location` header becomes a link the client clicks |
| partial model output -> a new provider prompt | the continuation call re-sends text the model itself just produced |
| `runtime_flags` env -> provider call count | a switch changes how many paid calls a run makes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-continuation | Information disclosure | `_continue_truncated`'s prompt | mitigate | the prompt carries the section's OWN `base_prompt` plus the partial text the same model just wrote — no new data source, no PII beyond what that section already had; bounded to ONE extra call per section, asserted as a call-count equality |
| T-23.5-06-D | Denial of service | unbounded continuation loop | mitigate | exactly one continuation, never a loop; a continuation that itself truncates appends a notice instead of calling again; a raising continuation is caught and degrades the section |
| T-23.5-06-COST | Denial of service | doubled synthesis spend | accept | worst case one extra `_SECTION_MAX_TOKENS` call per truncated section per run, under a switch that defaults OFF and is flipped on dev first (D-23.5-05); the alternative, delivering half a sentence, was measured on a $36.87 run |
| T-flag-default | Tampering | renderer + continuation defaults | mitigate | `NESTOR_CITATIONS_V2` and `NESTOR_SYNTHESIS_CONTINUE_TRUNCATED` both default `false`; the renderer's flags-off path is byte-compared to a golden generated from unmodified code, and the continuation's flags-off path is asserted as a one-call equality |
| T-23.5-06-T | Tampering | `resolved_url` rendered as a link | mitigate | the value is already bounded and scheme-validated at write time by `redirect_resolver._validated_target` and `_upsert_source`'s `_RESOLVED_URL_MAX_CHARS`; this plan only READS it, and falls back to `url` when it is empty |
