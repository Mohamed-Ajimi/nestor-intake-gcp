<objective>
Build the one genuinely-new frontend route: `/auth/action`, the branded in-app handler that consumes the Firebase password-reset action code (`oobCode`). It reads `mode`/`oobCode` from the URL, verifies the code, renders a neutral Dutch "Kies je wachtwoord" form, applies the new password via `confirmPasswordReset`, and navigates to `/auth/login`. One route serves both the invite set-password flow and the (later) forgot-password flow (D-11/D-12).

Purpose: Plan 03's `ActionCodeSettings` pins the invite link's continue URL to this route so the whole first-run flow stays in the app's look and language instead of Firebase's hosted page. Without this route, the invite mail's link is a dead end.
Output: `frontend/src/routes/auth.action.tsx`.
</objective>
