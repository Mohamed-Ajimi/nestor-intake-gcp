# Phase 23.6 — Rerun deep research with run history — Context

**Status:** Ready for planning
**Scope:** DEV ONLY (`project-cb01b861-cb4a-438d-b9a`). No prod promotion in this phase.

<domain>
## Task boundary
A superadmin can start another deep-research run on an intake that already has one, see every run the intake has
had (each with its own report and raw-output zip), and mark one finished run as the "chosen run" the final
report is based on (internal label — see revised D-23.6-02).
</domain>

<decisions>
## Locked decisions (operator, 2026-09-25)

- **D-23.6-01 — No attempt cap for superadmin.** Today `trigger_research` counts prior runs against a cap of 3
  (D-23.4-07, `_CAP_EXEMPT_RUN_STATUSES`). For a superadmin the cap does not apply. Every run still costs ~$40;
  the confirm dialog must say so. Non-superadmins cannot start research at all today (D-23.1-16) — unchanged.
- **D-23.6-02 — REVISED 2026-09-25 (operator): the pick is an INTERNAL "chosen run" label only.** Verified in code:
  the client never sees research-run output — `intake.$id.report.tsx` serves only the operator-uploaded PDF
  (`final_report_artifact_id`) once status is `delivered`; `intake.$id.results.tsx` shows validated answers.
  So the superadmin marks one finished run as "the chosen run" (the one the final report is based on); newest
  finished run is shown as chosen by default until one is marked. NOTHING client-facing changes: no client route,
  no mail, no PDF swap. Closes DEF-23.5-07-04 on that basis.
- **D-23.6-03 — Rerun button, same questions.** One click on the intake page starts a new run from the CURRENT
  approved questions and context pack. No status step-back to `decomposed` is required (today the trigger 409s
  unless status is `decomposed`). The existing path (status override back to `decomposed`, edit, start) keeps
  working. A rerun is refused while another run on the same intake is in flight (`RESEARCH_IN_FLIGHT`). A rerun on a
  `delivered` intake must leave the status `delivered` (GET /report 404s on any other status — the client would lose
  their report).
- **D-23.6-04 — History on the intake page.** A list of every run (newest first): started/finished time, status,
  cost if known, links to its run page, report and zip, and which one is the chosen run (internal label).
