# Phase 23.6 Plan 02: Run-history list + chosen-run verb Summary

Two superadmin-only verbs on `research_router`. `GET /intakes/{id}/research/runs` returns every run of an intake plus the explicitly chosen run id. `POST /intakes/{id}/research/runs/{run_id}/choose` marks one finished run as the internal chosen run and writes an audit row in the same transaction. The response shapes match the frozen contract that plan 03 typed in `frontend/src/lib/api/research.ts`; the key names were checked against that file.

## What was built

- **`_run_history_item(run)`** projects a row onto exactly the 9 contract keys. Datetimes go through `.isoformat()` or stay None. Cost is `str(Decimal)` or None, never `"0"`. Status is the engine literal, unchanged.
- **`list_research_runs`**: the gate is declared before the repo, with an in-body role re-check (404). The intake is resolved space-scoped, so a missing or out-of-scope intake gets 404 "Intake not found". Runs come from `list_for_intake` and are sorted by `(attempt, created_at)` descending. The chosen id is the one row with `chosen_at` set, or None. The docstring says this is a history read, not a live-status source (the SSE stream stays the authority), and that the newest-finished default is display-only.
- **`choose_research_run`** checks in this order: role 404, intake 404, run missing or belonging to another intake 404 "Run not found", archived intake 409, run not in `RESEARCH_SUCCESS` 409. It then calls `set_chosen` inside `repo.session.begin_nested()`, and an `IntegrityError` there becomes a readable 409. If `previous == run_id` it returns without writing an audit row. Otherwise it logs `research.run_chosen` with `{research_run_id, previous_research_run_id, attempt}`. The docstring states this is an internal label only and that adding any client effect needs a new operator ruling.
- The module docstring now lists both routes, and the route-count prose was updated from ELEVEN to THIRTEEN.
- `test_superadmin_gate.py`: both pins were raised from 11 to 13 (`checked == 13`, `total == 13`), each with the history comment.
