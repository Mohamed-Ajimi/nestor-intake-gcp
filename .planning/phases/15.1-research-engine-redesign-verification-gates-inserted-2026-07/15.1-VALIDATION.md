## Sampling Rate

- **After every task commit:** `python -m pytest nestor_pulse_sdk/tests/<file(s) the task touches> -x` via Cloud Build (no DB needed for the new gate files).
- **After every plan wave:** `gcloud builds submit tribunal --config=tribunal/cloudbuild.test-critical.yaml` (schema isolation, advisory lock, hash chain) **plus** the new gate files.
- **Before `/gsd:verify-work`:** full suite via `cloudbuild.test.yaml`. Assert **no NEW failures** — some carried tests require live provider keys and fail in a keyless build (known deferred chore, `13-PROOF-RESULTS.md`). An absolute-green assertion is only valid once that triage lands.
- **Max feedback latency:** ~5 min per Cloud Build submission for the targeted gate files.
