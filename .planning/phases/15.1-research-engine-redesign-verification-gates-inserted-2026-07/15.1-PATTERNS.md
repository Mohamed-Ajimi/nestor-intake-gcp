**Untrusted-output parser — the security-critical excerpt** (`grouping.py:94-114`). This is the
V5 control named in RESEARCH: index bounds-checked, missing entries defaulted, never
`json.loads` on raw model text. Copy the structure exactly, changing only the tuple payload:

```python
def _parse_tag_lines(text: str, n: int) -> list[tuple[str, str]]:
    """Parse 'INDEX | ENTITY | ATTRIBUTE' lines into [(entity, attribute)] of length n.

    Missing/garbled lines default to ('', '') so the caller can fall back to a
    per-claim singleton group (never drops a claim)."""
    out: list[tuple[str, str]] = [("", "")] * n
    for raw in (text or "").splitlines():
        line = raw.strip()
        if not line or "|" not in line:
            continue
        parts = [p.strip() for p in line.split("|")]
        if len(parts) < 3:
            continue
        idx_raw, entity, attribute = parts[0], parts[1], parts[2]
        m = re.search(r"\d+", idx_raw)
        if not m:
            continue
        idx = int(m.group())
        if 0 <= idx < n:
            out[idx] = (entity, attribute)
    return out
```

> **G-11 delta:** the gate's neutral default is **NOT** `("", "")`. A missing/garbled gate line
> must default to **KEEP-for-checking** and increment the `gate_errors` funnel counter. The
> *structure* (pre-filled list of length `n`, bounds check, never raise, never drop) is copied;
> the default *value* inverts.

**Batch helper — `resp.text` → candidates fallback, batch-level try/except, never raise**
(`grouping.py:117-146`), copy verbatim:

```python
async def _tag_batch(
    claims: list[dict[str, Any]],
    audited: "AuditedLLMClient",
    run_id: uuid.UUID,
    tenant_id: uuid.UUID,
) -> list[tuple[str, str]]:
    """Tag one batch of claims with (entity, attribute). Best-effort: on failure
    every claim in the batch gets ('', '') -> singleton groups."""
    block = "\n".join(
        f"{i} | {(c.get('text') or '')[:240]}" for i, c in enumerate(claims)
    )
    prompt = _TAG_PROMPT.format(claims_block=block)
    config = _make_config()
    kwargs: dict = {"config": config} if config is not None else {}
    try:
        resp = await audited.gemini_generate(
            run_id=run_id, tenant_id=tenant_id, model=_GROUPER_MODEL,
            contents=prompt, **kwargs,
        )
    except Exception as exc:  # noqa: BLE001
        log.warning("grouping: tag batch failed (%d claims): %r", len(claims), exc)
        return [("", "")] * len(claims)
    text = getattr(resp, "text", None)
    if not text:
        cands = getattr(resp, "candidates", None) or []
        if cands:
            parts = getattr(getattr(cands[0], "content", None), "parts", None) or []
            if parts:
                text = getattr(parts[0], "text", None) or ""
    return _parse_tag_lines(text or "", len(claims))
```

Two properties in `block` are security controls (RESEARCH § Known Threat Patterns) and must
survive into the gate prompt: **claim text truncated to 240 chars** and **output addressed by
index**, so injected claim text cannot address another claim's slot.

```python
def _norm(s: str) -> str:
    """Normalize a grouping-key token to alphanumerics only (lowercase).
    Merge-happy BY DESIGN: ... Over-merging is safe ...; under-merging would
    split a contradiction across groups and hide it — the failure we are fixing."""
    return re.sub(r"[^a-z0-9]", "", (s or "").lower())

    # ... inside group_claims():
    groups: dict[str, dict[str, Any]] = {}
    order: list[str] = []
    for i, claim in enumerate(claims):
        entity, attribute = flat_tags[i] if i < len(flat_tags) else ("", "")
        ne, na = _norm(entity), _norm(attribute)
        if ne:
            key = f"{ne}│{na}"
        else:
            # Untagged: keep it isolated (singleton) so it still gets verified.
            key = f"__singleton__:{i}"
        if key not in groups:
            groups[key] = {
                "key": key,
                "entity": entity.strip() or (claim.get("facet") or "?"),
                "attribute": attribute.strip() or "general",
                "claims": [],
                "stakes": "low",
            }
            order.append(key)
        g = groups[key]
        g["claims"].append(claim)
        # Inherit the highest stakes of any member.
        cs = (claim.get("stakes") or "med")
        if _STAKES_ORDER.get(cs, 1) > _STAKES_ORDER.get(g["stakes"], 0):
            g["stakes"] = cs

    result = [groups[k] for k in order]
```

**What must be KEPT — three hard contracts:**

1. **Signature is frozen:**
   `async def group_claims(*, claims, audited, run_id, tenant_id) -> list[dict[str, Any]]`
   (`grouping.py:149-155`). Called at `pipeline.py:350-352`.
2. **Return shape is frozen** (`grouping.py:158-165`) — `group_skeptic.run_group_skeptic` reads
   `group["entity"] / ["attribute"] / ["claims"] / ["stakes"]`, and `pipeline.py:355/371/416/419`
   read the same:
   ```python
   {
     "key":       "entity│attribute",   # normalized grouping key
     "entity":    str,                  # display entity (first non-empty seen)
     "attribute": str,
     "claims":    [claim_dict, ...],    # original claim dicts, order preserved
     "stakes":    "low"|"med"|"high",   # MAX stakes across members
   }
   ```
3. **Stakes inheritance stays MAX** — `_STAKES_ORDER = {"low": 0, "med": 1, "high": 2}`

```python
def _report_dir() -> Path:
    """Locate the committed run-report dir.

    Prefers the in-package `recorded/` copy — required in Cloud Build, where
    `gcloud builds submit tribunal` ships only the tribunal/ subtree and the
    repo-root `docs/` dir is absent from /workspace. Falls back to walking up
    for `docs/tribunal-run-reports/run-20260722-4cbb5311` (dev checkouts).
    """
    local = Path(__file__).resolve().parent / "recorded"
```

```python
    whitespace) and keeps the first occurrence. Removing the global 30-claim cap

        norm = re.sub(r"\s+", " ", norm).strip()
```

## Shared Patterns

### A. LLM egress — always through `audited`, always duck-typed

**Source:** `grouping.py:132-135`, `steps.py:796-802`
**Apply to:** `gates.py`, the clusterer, every new test

```python
        resp = await audited.gemini_generate(
            run_id=run_id, tenant_id=tenant_id, model=_GROUPER_MODEL,
            contents=prompt, **kwargs,
        )
```

Keyword-only, `run_id` + `tenant_id` always passed (audit hash chain, D-07). The parameter is
typed `"AuditedLLMClient"` under `TYPE_CHECKING` only, which is what lets a hand-written fake
satisfy it. **Do not add a `Protocol`, ABC, or an injectable `classifier: Callable`** — RESEARCH's
explicit anti-recommendation (it would create a second, untested production path that bypasses
the batching/parsing/fallback logic the CI test exists to prove).

### B. Best-effort failure handling — catch, log, return a neutral default

**Source:** `grouping.py:136-138`, `steps.py:803-807`, `stages.py:119-120`, `pipeline.py:801-802`
**Apply to:** every new batch helper and every new DB write

```python
    except Exception as exc:  # noqa: BLE001
        log.warning("grouping: tag batch failed (%d claims): %r", len(claims), exc)
        return [("", "")] * len(claims)
```

The `# noqa: BLE001` comment plus a one-line reason is the house style. Progress/cache writes are
explicitly documented as best-effort ("a progress write must never break the pipeline that is
reporting it"). **G-11 inverts only the default value, never the structure.**

### C. Tenant context before every tenant-scoped statement

**Source:** `pipeline.py:770`, `pipeline.py:794`, `worker.py:188`, `stages.py:101`
