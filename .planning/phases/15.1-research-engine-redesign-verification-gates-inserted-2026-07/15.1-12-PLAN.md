<objective>
Fix the publishing half of the verification report: carry `superseded_note` through the DTO, make
the `unverified` block impossible to publish as a contradiction of the funnel, and stop calling a
per-claim count "batches".

Purpose: 15.1-VERIFICATION.md records two publishing defects that make SC2 false. `_verdict_dto`
returns five keys and omits `superseded_note`, so `VerificationVerdictItem.superseded_note` is
unconditionally `None` on the wire no matter what is stored (CR-01 leg b). And because nothing
wrote verdict rows, `unverified.count == total_claims` shipped in the SAME payload as the honest
`funnel.checked` — the operator reads "checked: 380" beside "unverified: 1162 of 1162" (CR-02).
Plan 15.1-14 lands the writer that stops that in normal operation; THIS plan makes it impossible
even if the writer regresses, by deriving the unverified figure from the same funnel the
accounting block uses whenever no verdict row exists. WR-02's unit mislabel (a per-claim count
rendered as "gate batch(es)", overstating by up to 40x at the default `_GATE_BATCH = 40`) is fixed
in the same file.

**Wave numbering:** the gap-closure set CONTINUES phase numbering — plans 01-10 hold waves 1-6,
closure plans hold waves 7-9. This plan is wave 7 and depends on nothing.

**No frontend change is needed FOR THIS PLAN'S CHANGES.** The fallback keeps `unverified`'s exact
three-key shape and makes its numbers agree with the funnel by construction, so
`VerificationReport.tsx`'s unverified block renders a coherent payload with no edit and no new i18n
key. Do NOT read that as a phase-level statement: the PHASE does ship a frontend rebuild. Plan
15.1-16 edits that same component for a different reason — `report.verdicts.superseded` (the G-06
verdict class, which this plan's DTO feeds) has no rendering site today, and the `superseded_note`
this plan starts emitting reaches the browser and is displayed nowhere. Plan 15.1-15 Step 15.1.g
owns the frontend build and deploy.

Output: a report shaper that publishes the caveat, cannot contradict itself, and labels its own
units truthfully.
</objective>
