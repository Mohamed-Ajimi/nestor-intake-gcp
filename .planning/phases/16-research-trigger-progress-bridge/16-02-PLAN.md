execution path. It never edits the Tribunal engine; it only chooses a brief and mirrors run state.

  run_with_session_release(identity, read_fn, call_fn, write_fn, *, on_error=None)
  - read_fn(session) MUST return a PLAIN dict (never ORM rows).
  - call_fn(dto) runs with NO DB connection held (engine.pool.checkedout() == 0 across the poll loop).
  - write_fn(session, dto, result) runs in a fresh tenant_session (GUC re-issued).
  - on_error(session, dto, exc) finalizes the row to EXACTLY "failed" on any exception.
  - tenant_session(identity) is the scoped-tx contextmanager for the per-tick mirror UPDATE.
