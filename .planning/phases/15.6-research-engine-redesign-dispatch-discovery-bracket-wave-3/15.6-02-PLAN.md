<objective>
Give the engine the right to ask a question the client did not — bounded, sourced, and traceable.

Purpose: on V-01 the orientation pass produced `brief_conflicts` and **not one of them ever reached
a report or a research call**. This plan turns a sourced conflict into a research question, caps how
many, and carries the quote and URL that provoked it all the way to the client-facing section that
already exists. Provenance is also an Art. 12 audit-trail requirement with a **2026-08-02 deadline**.

Timing is what makes it affordable: discovery fires off the ORIENTATION pass, BEFORE research. Richer
discoveries surface from the research text itself, but by then the money is spent — those are
"questions for the next run" and are explicitly NOT in scope here.

Output: `discovery_bracket.py` (new) and a new test file. Both PURE — no LLM call, no DB, no clock.

**`discovery_question_text(conflict) -> str`** — pure, deterministic, engine-authored. Composes ONE
research question from a conflict. The frame is the engine's; the two model-authored fields are
collapsed to single spaces and truncated to `_DISCOVERY_TEXT_CHARS` **each, separately**. Shape:

  `The brief assumes: <assumption>. A source read during orientation says instead: <world_says>

   this client.`

Three things to write into the docstring because a future reader will want to change them:
1. **The frame is English inside a Dutch run, deliberately.** `_angle_query`'s own framing sentences
   already are (`research_division.py:445-452`), and `_d7_language_sentence` is what sets the report
   language, always last. A second language mechanism here would be a second source of truth.
2. **No LLM phrases this question.** A model asked to phrase a discovered question is a model that
   can invent one; the frame is what makes "no invention" mechanical rather than a prompt sentence.
   The same file that owns the scope rule already says a prompt sentence is not a control.
3. The URL is included because the client will see it in the report anyway, and it is already
   allowlisted to http(s) upstream at `workshop.py:701-716`.

**`allocate_discovery(brief_conflicts, client_questions, *, slots=None, per_parent_cap=None)
-> tuple[list[dict], dict[str, int], list[str]]`** returning `(questions, per_parent_counts, notes)`.

Rules, each with its own comment:

1. `slots` / `per_parent_cap` default to the two constants; `slots <= 0` returns `([], {}, [])`.
2. **NO SOURCE, NO SLOT.** A conflict is a candidate only when `world_says` is non-empty AND
   `source_url` starts with `http://` or `https://`. A conflict without one is DROPPED, counted, and
   named in a note — dropping it silently would hide the one thing this rule exists to enforce.
3. **Parent.** `conflict["question"]` when that string is in `client_questions`, else
   `DISCOVERY_PARENT`. Never read a parent from anywhere else.
4. **Order is input order** — orientation order, which is client-question order. Deterministic and
   replayable; do not sort, do not rank by anything.
5. Dedupe on `(parent, assumption, world_says)` in case the caller did not.
6. **Per-parent cap applies to every parent value INCLUDING `DISCOVERY_PARENT`.** One rule, no
   exemption: a cross-cutting flood would otherwise take all five slots. State that choice.
7. Stop at `slots`. **There is no floor and no padding.** Zero candidates returns zero questions —
   the unused slots roll back to the mandate, which the caller effects by keeping its full group
   ceiling. Say in the docstring that unused slots roll to the mandate and NEVER into more discovery.

Each returned question dict is winner-shaped so it survives `_normalise_winners` unchanged:

```
{"text": discovery_question_text(conflict),
 "parent": <label or DISCOVERY_PARENT>,
 "parents": [<same>],
 "rank": 0,                 # STAMPED BY THE CALLER after the mandate winners — see below
 "langs": [],
 "source": "discovery",
 "scope_injected": False,
 "bracket": "discovery",
 "provenance": {"question": <origin label, verbatim>, "assumption": ..., "world_says": ...,
                "source_url": ...}}
```

Document why `rank` is 0 here and stamped by the caller: rank drives stakes via `_stakes_for_rank`,
and a discovered question must rank BELOW every client winner — the mandate can never be displaced.

`per_parent_counts` is a plain `dict[str, int]`, returned so the caller can log the distribution.

**`partition_discovery(questions) -> tuple[list[dict], list[dict]]`** — pure, never raises. Splits the
allocated questions into `(riders, cross_cutting)`: a rider is any question whose `parent` is NOT
`DISCOVERY_PARENT`, a cross-cutting one is any whose parent IS. **This is D-W3-5's whole shape in one
function**: riders travel inside the mandate group of the client question they belong to and cost
nothing extra; only a cross-cutting question earns the single `d1` group, and with no cross-cutting
question **there is no discovery group and discovery consumes no group slot at all** — which is why
V-01's three questions land at 9-12 calls rather than 15. Write that arithmetic into the docstring.
Order is preserved inside each half, so the caller's allocation order still governs.

**`annotate_conflicts(brief_conflicts, questions) -> list[dict]`** — pure. **`questions` is the set of
questions that were actually DISPATCHED, not everything `allocate_discovery` returned** — a rider shed
by `question_grouping.attach_discovery_riders`, or a cross-cutting question that never got a group,
must NOT be annotated. It still reaches the client: without a `researched_as` key it renders as a
plain brief-vs-world conflict, which is the honest statement that the evidence raised it and this run
did not research it. Say that in the docstring. Returns a NEW list of the
SAME LENGTH AND ORDER as `brief_conflicts`, in which each entry whose `(question, assumption,
world_says)` matches a dispatched discovery question gains `"researched_as": <the question text>`.
Entries are copied, never mutated in place. **Annotate, never append**: appending a second row would
print the same conflict twice in the report, once with the clause and once without.
