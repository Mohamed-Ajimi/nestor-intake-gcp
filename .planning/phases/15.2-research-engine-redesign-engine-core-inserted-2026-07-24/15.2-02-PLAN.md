**4. `def retry_after(exc: BaseException) -> float | None`.** Best-effort, never raises. Look for a
case-insensitive `retry-after` key in `getattr(exc, "headers", None)` and in
`getattr(getattr(exc, "response", None), "headers", None)`, then a bare `getattr(exc, "retry_after", None)`.
Accept only a value that parses as a non-negative number of seconds (`float(str(v).strip())`);
an HTTP-date form returns `None`. **Clamp the result to `[0.0, RETRY_AFTER_MAX_S]`** — an
unclamped provider-supplied sleep is a denial-of-service vector (T-15.2-03). Docstring says so.

**5. `async def with_retry(fn, *, attempts=RETRY_ATTEMPTS, base_s=RETRY_BASE_S, on_retry=None,
label="", breaker=None)`.** Semantics, following the `gates.py:379-393` structure:
- Loop `for attempt in range(attempts)`; `return await fn()` on success. On success also call
  `breaker.record_success()` when a breaker was passed.
- On exception: record it on the breaker if one was passed (`breaker.record_failure(exc)`), then
  **re-raise immediately** if `attempt + 1 >= attempts` or `not is_transient(exc)`. Hard errors are
  never retried — retrying an account-level refusal only produces more of them, faster.
- Backoff: `wait = random.uniform(0.0, base_s * 2 ** attempt)` when `RETRY_JITTER` else
  `base_s * 2 ** attempt`. Full jitter, because 529 is a global capacity signal and naive
  exponential backoff lands every client in the same overload window.
- `retry_after(exc)` is not None ⇒ it **wins** over the computed wait (Anthropic's documented rule).
- If `on_retry` is not None, `await on_retry(attempt + 1, attempts, wait, label)` before sleeping.
  Wrap that call in `try/except Exception` and log at WARNING — a feed write is best-effort and must
  never break the run (Shared Pattern 6), while the retry itself must not be swallowed.
- If a `breaker` was passed and it is open before the first attempt, raise `CircuitOpenError`
  without calling `fn` at all.
- Never return `None` on exhaustion: the last exception is re-raised. Add a `raise last_exc` /
  `raise AssertionError("unreachable")` tail so no code path returns silently.

**6. The F8 `pause_turn` continuation helper.** Constant `PAUSE_TURN = "pause_turn"`,

```
class PauseContinuation:  # bounded, per-loop, not global
    def __init__(self, *, max_pauses: int = MAX_PAUSE_CONTINUATIONS, label: str = "") -> None
    used: int
    def consume(self, resp: Any) -> bool
```
