**`build_fact_list_prompt_block(*, language: str = "") -> str`**
Returns the instruction block a provider appends to its research prompt. Mirror
`_build_distiller_prompt`'s construction style (a single returned concatenated string, a
conditionally-built `lang_rule`). The block must specify:
- Emit the fact block **once, at the very end of the report, after any source list**.
- One fact per line, TAB-separated. Do NOT use JSON, bullets, or numbered lists.
- Column order: `STATEMENT<TAB>SOURCE_URL<TAB>QUALITY<TAB>CERTAINTY<TAB>EVIDENCE`.
- `STATEMENT` = one self-contained factual assertion (no conjunctions joining two facts).
- `SOURCE_URL` = the single URL supporting it; a markdown link `[domain](url)` is also accepted.
- `QUALITY` = one of `official`, `press`, `other`.
- `CERTAINTY` = `certain` (corroborated by two or more independent sources) or `single` (found only
  once — double-check).
- `EVIDENCE` = the shortest VERBATIM sentence or phrase copied EXACTLY from your own report that
  states this fact, in the report's original language, do NOT translate it. Explain why in the
  prompt: it is used to locate the passage and remove it if the fact is later discredited. (This is
  RESEARCH's option (a) — without it a refuted D8 fact cannot be scrubbed, because a D8 statement is
  the model's paraphrase, not a verbatim span. `scrub_research` deletes by the `evidence` span.)
- Blank lines and lines without at least one TAB are ignored.
- Between `NOT_FOUND_START` / `NOT_FOUND_END`: one line per thing you looked for and could not
  establish. Emit the block even if empty.
- `language`, when non-empty, adds a sentence requiring `STATEMENT` in that language while
  `EVIDENCE` stays in the report's original language — mirror `_build_distiller_prompt`'s
  `lang_rule` construction exactly.

**`strip_fact_block(text: str | None) -> str`**
Removes the machine-readable region so the fact block never reaches synthesis or the delivered
report. Scan line-by-line (do not use a multiline regex over a 53 KB body): drop from the first line
whose stripped form equals `FACTS_START` through the line whose stripped form equals `FACTS_END`,
and likewise for the `NOT_FOUND_*` pair. A dangling `FACTS_START` with no `FACTS_END` drops
everything to end of text (mirror `intake.py:296`). Sentinels absent ⇒ return the input unchanged.
`None`/`""` ⇒ return `""`. Never raise.
