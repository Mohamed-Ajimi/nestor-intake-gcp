**Class `StageFeed`** with this exact public surface:

  `self._lock = asyncio.Lock()`, `self._dirty = False`, `self._closed = False`,
  `self._writer_task: asyncio.Task | None = None`, `self._overflow = 0`.
- `async def declare(self, names: Sequence[str], *, status: str = "pending", task_prompts: Sequence[str] | None = None) -> list[int]` —

  **deterministic** path (mirrors `pipeline.py:445-452`, which declares every angle as `pending`

  scheduling.
- `async def add(self, name: str, *, status: str = "pending", task_prompt: str | None = None, **fields) -> int` —
  append one row, return its integer handle.
- `async def update(self, handle: int, **fields) -> None` — merge `fields` into the row at
  `handle`. Accepted field names: `name`, `status`, `task_prompt`, `cost_usd`, `facts`,
  `audit_id`, `retry`. An out-of-range handle logs a WARNING naming run / stage / handle and
  returns (never raises, never appends a phantom row).
- `async def mark_retry(self, handle: int, *, attempt: int, max: int, wait_s: float) -> None` —
  sets `status="retry"` and `retry={"attempt":…, "max":…, "wait_s":…}` (R5; `"retry"` is already a
  legal `StageDetailItem.status` literal at `schemas.py:162`). This is the callback surface
  plan 15.2-02's `with_retry(on_retry=…)` binds to.
- `async def set_summary(self, *, duration_s: float | None = None, actions: int | None = None, items_read: int | None = None, cost_usd=None) -> None` —
  the `StageSummary` rollup; `None` fields are omitted.
- `async def flush(self) -> None` — cancel any pending debounce task and write immediately.
- `async def close(self) -> None` — `flush()`, then set `self._closed = True`. **After close every
  mutation is a no-op logged at WARNING.** This matters: `set_stage` also sets
  `run.current_stage = stage_key`, so a late write after the pipeline has advanced would drag the
  operator's view backwards to a finished stage.
- Support `async with StageFeed(...) as feed:` via `__aenter__`/`__aexit__` (exit calls `close()`,
  including on exception).

**Field normalisation applied inside every mutation, before the row is stored:**
- `name` → `str(...)`, stripped, truncated to 120 chars.
- `status` → clamped to `_STATUS_VOCAB`, default `"pending"`.
- `task_prompt` → `truncate_task_prompt(...)`.
- `cost_usd` → `str(value)` when not `None` (a `Decimal` must reach JSONB as a string —
  `StageDetailItem.cost_usd` is `str | None`). Never `float()`.
- `facts` → `int(...)`, defensively ignored if it cannot be coerced.
- `audit_id` → `str(...)`.
- `retry` → a dict with only the `attempt` / `max` / `wait_s` keys.
- Any key whose value is `None` is **omitted from the emitted dict** (keeps the JSONB small and
  keeps legacy `{name,status}` rows byte-identical to today's).

**Overflow (`_FEED_MAX_ITEMS`)**: when an append would exceed the cap, increment `self._overflow`
instead of appending, and log a WARNING once per 50 dropped rows naming run / stage / count. The
snapshot then carries a final synthetic row
`{"name": f"+{self._overflow} more agent(s) not shown (feed row cap {_FEED_MAX_ITEMS})", "status": "done"}`
— fail loud in words, never a silent truncation (cross-cutting rule 6).

**The debounced writer loop:**
- Every mutation sets `self._dirty = True` and calls `self._ensure_writer()`.
- `_ensure_writer()` creates `self._writer_task = asyncio.create_task(self._writer_loop())` when
  no task exists or the existing one is `done()`.
- `_writer_loop()` loops: `await asyncio.sleep(self._debounce_s)`, then `async with self._lock:`
  — if not `self._dirty`, return; otherwise build the snapshot, set `self._dirty = False`, and
  `await self._writer(self._run_id, self._tenant_id, self._stage_key, detail=snapshot)`
  **inside the lock**. Holding the lock across the write is deliberate: it serialises the
  full-snapshot writes so a slow write cannot be overtaken by a newer one and lose rows — which is
  the exact defect (F9) this class exists to prevent. Debouncing keeps the frequency low enough
  that the stall is not material.
- The whole body of `_writer_loop` is wrapped in `try/except asyncio.CancelledError: raise` +
  `except Exception as exc: log.warning(...)` so a writer failure never propagates
  (`stages.py:125-126` contract) and never kills the loop silently without a log line.
- `flush()` cancels the task (and awaits its cancellation, suppressing `CancelledError`), then
  performs one locked snapshot+write if `self._dirty`.
