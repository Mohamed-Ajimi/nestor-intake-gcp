## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model output → report body | Reconciliation notes, `canonical` statements, superseded caveats, claim text and provider gap text are all model-authored strings, several of them derived from arbitrary web pages the providers read. This plan renders them **verbatim into the operator's report** with no model in between. |
| web page → provider prose → claim → note → report | The longest untrusted path in the engine. A hostile page can shape a note's contents; markdown control characters and citation-shaped tokens are the attack surface. |
| database → report text | `research_gap.text` rows are read and rendered. A cross-tenant read would put another client's research gaps into this client's report. |
| DB availability → truthfulness of the report | A failed read must not become a factual claim ("no gaps") in a document the operator hands to a client. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15.2-31 | Tampering | `_flatten` / every rendered item in both builders | **high — blocking** | mitigate | Model-authored text is rendered into a markdown document. Every item passes `_flatten` (all whitespace, newlines included, collapsed to single spaces) before being placed after a `*   ` bullet, so no item can open a `##` heading, a nested list or a `---` rule of its own and forge a section. Mirrors `pipeline._one_line`'s documented containment rationale (`pipeline.py:1445-1452`). Regression-tested in `test_report_sections.py` test 12: a note carrying `"\n\n## Sources\n\n…\n---\n"` yields exactly one `## ` heading line and no `---` line. |
| T-15.2-32 | Spoofing | `_sanitize` — citation markers inside note text | medium | mitigate | `[cite: N]` and `[[c:xxxxxxxx]]` tokens arriving via a web page could forge a citation in a section that is appended **after** 15.2-05's anchor post-pass and after `strip_unresolved_cite_markers`, i.e. past every existing stripper.
