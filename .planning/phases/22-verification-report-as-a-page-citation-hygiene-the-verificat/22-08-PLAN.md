<objective>
Collapse the citation list by default without making a `[n]` click do nothing, and make a long
document reachable.

Purpose: D-22-3, operator verbatim — *"the list of citation should be hidden by default and user can
expand and see"*. And D-22-4's read-time dedupe means one `[n]` now maps 1:1 to a distinct source,
which is what makes "sources" the honest noun beside the collapsed trigger.

⚠ **This plan exists partly to stop a defect the phase would otherwise SHIP.** `CitationPanel`
renders today at `VerificationReport.tsx:380-386`, INSIDE the citation-list `div`. Collapsing that
list would make a `[n]` click from a verdict row render the panel inside a collapsed container —
invisible, hundreds of pixels down the page. The click would appear to do nothing. Hoisting the panel
to a page-level `Sheet` is the fix, and because `openCitation` is already shared across sections it
fixes markers from ANY section at once.

Output: a nav rail, a collapsed-by-default citation list with a visible count, and a Sheet.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API → browser | `citation.title` and `citation.publication_date` are engine-authored strings from remote page metadata, now rendered in a third place (the list rows). |
| modal boundary | The Sheet is a Radix Dialog: focus trap, Esc, scroll lock. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-24 | Tampering | stored XSS via `citation.title` in a list row | mitigate | `title` is a plain React text child, never routed through `MdText` / `ReactMarkdown`. `rehype-raw` is a project dependency, so this constraint is stated explicitly rather than assumed. |
| T-22-25 | Information Disclosure | SSRF via a citation URL | mitigate | Unchanged: `CitationPanel` renders stored `snapshot_text` and never re-fetches the live `url` (T-15-15). The list row renders no URL and makes no request. |
| T-22-26 | Denial of Service | an unbounded expanded list | accept | Deliberate — 22-UI-SPEC §3.3 bars a `max-h`, because capping a list the operator just chose to expand recreates the complaint that started the phase. The list is one row per distinct source on one run. |
| T-22-27 | — (a11y) | an unlabelled modal | mitigate | `sr-only` `SheetTitle` with the existing `citation.regionLabel`; focus trapped and restored by Radix; `aria-expanded` supplied by Collapsible; `aria-current` on the active rail anchor. |
| T-22-SC | Tampering | npm/pip/cargo installs | mitigate | **No package is installed and no registry is contacted.** `collapsible` and `sheet` are already vendored. `package.json` / `package-lock.json` unchanged is an acceptance criterion. No install checkpoint required. |
