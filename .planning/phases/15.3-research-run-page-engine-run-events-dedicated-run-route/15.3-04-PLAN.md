<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model-authored search input → event text | The model chooses the query string that becomes a feed row |
| provider response / fetched page → event text | Third-party content becomes a persisted operator-visible string |
| provider job id → event text | An opaque external identifier could be interpolated into a stored row |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15.3-30 | Information disclosure | fetched-URL query strings in a feed row | mitigate | the fetch event emits the HOST only; the full URL stays in the audit body reached through the drill-down |
| T-15.3-31 | Information disclosure | a model-authored query carrying an identifier | mitigate | the event carries the ALREADY-SCRUBBED, ALREADY-CLAMPED dispatched value; `emit` scrubs again at the choke point |
| T-15.3-32 | Tampering | an unvalidated provider job id persisted | mitigate | `safe_job_id` before any interpolation; the provider is named without the id when rejected |
| T-15.3-33 | Denial of service | a chatty model flooding `thinking` rows | mitigate | one `thinking` per tool round in the own-researcher; a poll-attempt stride in the client; the emitter's bounded deque is the backstop |
| T-15.3-34 | Denial of service | an emit raising inside a 35-minute paid poll | mitigate | `emit` is sync and never raises; test (d) drives a raising recorder through the real call path |
| T-15.3-35 | Tampering | npm/pip/cargo installs | accept | no new dependency |
</threat_model>
