<objective>
Carry the engine's event cursor across the seam onto the existing SSE frame, so the run page can
tell that new events exist without a second connection and without downloading a thousand rows
per tick.

Purpose: D-05 rejects a second transport because two connections can disagree about when a run
ended. A cursor on the EXISTING frame keeps the SSE stream the sole authority on terminality
while making the events a pull, not a push. Plan 15.2-24 set the exact precedent by carrying
`started_at`/`completed_at` across this same seam for this same reason.

Output: intake migration `0013`, the mirrored column, and the cursor on the wire frame.
</objective>
