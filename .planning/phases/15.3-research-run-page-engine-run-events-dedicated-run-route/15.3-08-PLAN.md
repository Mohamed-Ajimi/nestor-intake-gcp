<objective>
Give the run its page: a flat route at `/admin/pulse/runs/:runId`, the transport that fills it,
the entry point that leads to it, and the feed body the operator designed.

Purpose: D-01 in the operator's own words — "running a deep research should open its own page …
users can close the page and reopen it to check advancement, timer shouldn't restart each time u
check on the page." Today the run is one card partway down an intake page, with no URL, and its
feed is a 28rem scroll area nested inside the page's own scroll. The feed half is the part of the
design that is better than what ships today, and the prototype's header comment names exactly
what must survive: the blinking cursor on the latest line, explicit dispatch headers with
indented agent children, completed phases auto-collapsing to a two-line preview, per-phase
summaries, the live badge, and one full-height page with a single scroll.
