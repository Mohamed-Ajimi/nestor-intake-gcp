<interfaces>
Consumed from plan 15.3-01, unchanged. NO new kind and NO new meta key is added by this plan.

    run_events.emit_safe(run_id, stage=..., kind=...,
                         build=lambda: (text, meta))   # sync, never raises

USE `emit_safe`, NEVER `emit`. Arguments are evaluated BEFORE the callee is entered, so
`emit(..., text=f"{parsed['decision']}")` raises `KeyError` at the call site no matter how
defensive `emit`'s body is. `emit_safe` takes a zero-argument callable returning `(text, meta)`,
so every f-string, subscript and `.get()` chain runs inside the emitter's try. Do NOT hand-write
a `try/except` per site: `grep -c "run_events.emit(" <file>` == 0 is machine-checkable, per-site
discipline is not.

Stage keys used here: `intake` for brief parsing, `workshop` for everything the workshop does.
`workshop` is a real `ENGINE_STAGES["tribunal"]` key with label "Question workshop" — declared
by 15.2 plan 03. Do not invent a stage key.
</interfaces>
