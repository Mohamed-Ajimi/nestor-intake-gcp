## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator click to a paid or irreversible action | Stop, Resume and Retry each spend or destroy money that has already been spent |
| chain verdict to download affordance | A failed hash chain must not yield raw output |
| audit body to DOM | An already-redacted LLM request/response is rendered to the operator |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15.3-100 | Repudiation | raw output served on a broken hash chain | mitigate | the download element is ABSENT in the `broken` branch, asserted in acceptance criteria; the server's `chain_status == "verified"` gate is the authority and the UI mirrors it |
| T-15.3-101 | Elevation of privilege | a client-role user reaching an audit body | mitigate | every read is superadmin-gated server-side; the component lives under `components/research/` and an acceptance criterion asserts no client route imports it (D-08) |
| T-15.3-102 | Denial of service | an accidental Stop burning an unrefundable run | mitigate | the POST fires only from the `AlertDialogAction` handler; the Stop button itself cannot send |
| T-15.3-103 | Denial of service | a retry on a parked run discarding paid checkpoints | mitigate | Retry is not rendered under `parked`; Resume and Retry are distinct components of the branch map |
| T-15.3-104 | Information disclosure | an audit body exposing a provider key | accept | bodies are redacted at upload server-side and carry no hash/prev_hash (`AuditBody`, `runs/api.py`); this plan adds no new exposure |
| T-15.3-105 | Tampering | npm/pip/cargo installs | mitigate | no dependency added; `npm ci` only; `package-lock.json` unchanged |
</threat_model>
