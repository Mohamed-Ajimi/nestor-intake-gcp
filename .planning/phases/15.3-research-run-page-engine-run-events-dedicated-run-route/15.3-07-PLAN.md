<objective>
Expose the engine's event history to the operator surface through the intake backend, and give a
standalone run URL the one thing it lacks: a way to find its own intake.

Purpose: D-08 says the run page is superadmin-only by placement AND by API authorization, and the
intake backend is the SOLE caller of Tribunal — the frontend never calls it directly. D-01 asks
for a genuinely standalone, bookmarkable URL, which means `/admin/pulse/runs/{runId}` must work
from a cold open with no intake id in hand.

Output: `get_run_events` on the seam client, two new superadmin routes, and their denial matrix.
</objective>
