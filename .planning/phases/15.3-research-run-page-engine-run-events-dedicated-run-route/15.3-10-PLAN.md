<objective>
Make the page honest about every state the run can actually be in, and stop the two states that
most need evidence from being the two that throw it away.

Purpose: the prototype models three states (idle / running / done). Production has eight. Two of
them carry traps already learned the hard way and re-stated in D-11: `completed_degraded` renders
the SUCCESS card, because a degraded run still cost around forty-five dollars and keeps its
download, its verification report and its frozen feed; and `parked` renders its OWN card, because
routing it to the failure card offers a retry that discards every checkpoint the engine already
paid for.

Output: `RunStatusCard.tsx` with all eight branches, mounted above the feed, with en/nl/fr keys.
</objective>
