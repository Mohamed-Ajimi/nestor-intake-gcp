  <action>
Add a module-private constant and helper next to the distiller constants (steps.py ~1120):

  `_DISTILLER_SEPARATORS: tuple[str, ...] = ("\t", "<TAB>", "|||", "|")`
  `_DISTILLER_SPACE_RUN = re.compile(r" {2,}")`
  `def _split_distiller_line(line: str) -> list[str] | None`

Semantics, exactly: try each literal separator IN ORDER and return
`[p.strip() for p in line.split(sep, 2)]` on the first one present; if none is present, try
`_DISTILLER_SPACE_RUN.split(line, maxsplit=2)` and return it only when it produced more than one
part; otherwise return `None`.

THE ORDER IS THE CONTRACT, not a style choice, and both halves of it are load-bearing:
`<TAB>` before `|||`/`|` so a placeholder-copying model is read correctly, `|||` before `|` because
every `|||` line also contains `|`, and the 2+-space run LAST because it is the only separator that
can appear inside ordinary prose. Say that in the docstring, and record the V-01 origin (two of four
calls in one batch at temperature 0.0 copied the placeholder; 278 claims were dropped on a string
comparison whose only trace was `log.debug`, which production does not serve).

`line.split("\t", 2)` with one call to `_split_distiller_line`. Keep the `None` case as today's
`log.debug` skip, and keep every downstream rule byte-identical: the `< 10` drop, the `general`
facet fallback, the unknown-facet `log.debug`, and the `found_by` construction from the
caller-supplied `provider` (a model must never set its own attribution — T-15.2-60).
