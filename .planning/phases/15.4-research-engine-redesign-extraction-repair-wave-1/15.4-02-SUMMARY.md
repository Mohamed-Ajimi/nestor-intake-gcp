## Deviations from Plan

### [Rule 1 — Contradiction in the plan] The index assertion is scoped to executable code

- **Found during:** Task 2, before writing the test.
- **Issue:** Task 1 requires the migration docstring to state "`idx_source_tenant_content_hash` is NOT dropped, recreated or altered". Task 2 requires the test to assert the migration source "contains … no occurrence of `idx_source_tenant_content_hash`". Written literally, the Task 2 test fails against the Task 1 file. One of the two had to give.
- **Fix:** the docstring keeps the invariant (that is what a reviewer reads); the scan strips docstrings and comments via `ast.unparse` and asserts over what can execute. A real `op.drop_index("idx_…")` survives that stripping string-argument and all, so nothing is lost — and `test_the_scan_bites_on_a_deliberately_bad_migration` proves exactly that by running the same helpers over a migration with the name in a docstring, a comment **and** a live `op.drop_index`.
- **Strengthened at the same time:** the primary assertion became an **allowlist** (`upgrade` = two `add_column` on `source`; `downgrade` = two `drop_column`; four ops total) rather than the plan's denylist. A denylist only rules out the harm someone thought to name.
- **Files:** `tribunal/nestor_pulse_sdk/tests/test_source_resolution.py`
- **Commit:** `cbd2850`

### [Rule 2 — Removed a trap] Dropped the "this plan wires nothing" assertion

- **Found during:** Task 2 self-review.
