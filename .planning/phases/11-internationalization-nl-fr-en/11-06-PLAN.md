<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pre-login browser choice → localStorage | Untrusted display preference before any session |
| boot /me read → changeLanguage | Server-authored locale drives the UI language |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-03 | Elevation of Privilege | pre-login locale choice | mitigate | The pre-login choice only sets display language + localStorage; persistence goes through the token-derived PATCH (11-02) after auth — never widens access (Task 1/3) |
| T-11-09 | Tampering (hydration) | boot changeLanguage | mitigate | changeLanguage runs only in the client post-auth settle, never on an SSR'd node (Pitfall 1); pre-login detect is `typeof window`-guarded (Task 3) |
| T-11-10 | Info Disclosure | locale not a claim | accept | Locale persists in Cloud SQL, never a Firebase claim (no token re-mint / claim leak surface) (Task 3) |
</threat_model>
