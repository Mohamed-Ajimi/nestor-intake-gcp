Notes for the redesign.
  • Everything is loaded. No inner scroll areas — the page is the scroll. The left rail is the only sticky navigation, plus the run header.
  • The elapsed clock counts from started_at, not from page load — closing and reopening shows 18:42, not 00:00. The header also states the absolute start time so the number is checkable.
  • Every agent carries its own log, collapsed by default, expanded here for the four states that matter. Levels: INFO, WARN, ERROR, plus PROMPT/DATA for payload blocks.
  • "Problems only" hides INFO and payload lines, per-agent or run-wide, so a 200-line run collapses to the 9 lines that matter.
  • Parallel dispatch is explicit — the four stream lanes in stage 03 show fan-out, per-stream model, and per-stream failures at a glance.
  • A long poll is visibly not a stall. The heartbeat line and the 634s warning both say so in words. This is the single most expensive misreading this system has produced.
  • A failure explains itself. Angle 06 shows the 403, the resulting poisoned tool loop, and the consequence — instead of the word "failed".
